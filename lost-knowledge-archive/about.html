About the Archive

Gather carefully. Question everything. Preserve what matters.

This starter site is built for a collection that can be strange, speculative, historical, spiritual, technical, or symbolic while still staying organized.

Entry Format

Each entry can include a short summary, why it matters, source notes, reliability level, related entries, and open questions.

Source Notes

Mark whether something is documented, disputed, legendary, reconstructed, or personal interpretation. That keeps the mystery sharp and the archive trustworthy.

Submission Path

For now, collect new fragments in a notes file or spreadsheet. Later, this page can become a real submission form through a free form service.

Free hosting works well for this version because it is a static site.
